สแกน QR ที่โต๊ะ) เข้าคิวเดียวกัน เรียงตามเวลาที่จะมาถึงจริง

## ฟีเจอร์หลัก

**ฝั่งลูกค้า**
- ดูสถานะคิวปัจจุบันโดยไม่ต้องล็อกอิน
- เข้าสู่ระบบด้วยเบอร์โทร + OTP (จำลอง)
- เลือกเมนู ปรับแต่ง (เครื่องเคียง/ความเผ็ด/หมายเหตุ) ใส่ตะกร้า สั่งซ้ำเมนูเดิมได้
- จองคิว ระบุเวลาที่จะมาถึง / กดมาถึงตอนนี้เลย
- ชำระเงินผ่าน QR Code (จำลอง)
- ดูคิว + ประวัติออเดอร์ของตัวเอง แบบ real-time
- ตั้งค่าโปรไฟล์ (ชื่อเล่น)

**ฝั่งร้านค้า**
- เข้าสู่ระบบด้วยเบอร์โทร + OTP จุดเดียวกับลูกค้า (ระบบตัดสิน role อัตโนมัติ)
- ดูคิวปัจจุบันทั้งหมด พร้อมรายละเอียดออเดอร์ครบ
- สรุปเมนูที่ต้องทำ จัดกลุ่มตามช่วงเวลา
- จัดการเมนู (เพิ่ม/ลบ/เปิด-ปิดขาย)
- พิมพ์ใบเสร็จ — ระบบถามหลังกด "ทำเสร็จแล้ว" ว่าต้องการพิมพ์ใบเสร็จหรือไม่
  (ไม่พิมพ์ตอนนั้นจะไม่สามารถพิมพ์ย้อนหลังได้ ใช้ print dialog ของเบราว์เซอร์)

## ข้อมูลสำหรับทดสอบ

- เบอร์ร้านค้า (demo): `0811111111`
- เบอร์ลูกค้า: กรอกเบอร์อะไรก็ได้ (10 หลัก)
- รหัส OTP: สุ่มใหม่ทุกครั้ง แสดงบนหน้าจอโดยตรง (ไม่ส่ง SMS จริง)

## ข้อจำกัดสำคัญ (Prototype)

โปรเจกต์นี้เป็น Client-side prototype ล้วนๆ ไม่มี backend/database จริง ข้อมูลทั้งหมดอยู่ใน
หน่วยความจำของเบราว์เซอร์ (reload หน้าแล้วข้อมูลหาย) ส่วนที่จำลองไว้ทั้งหมด:
- OTP: สุ่มแล้วแสดงบนจอ ไม่ได้ส่ง SMS จริง
- QR Code ชำระเงิน: scan ได้จริงแต่เป็นข้อความ placeholder ไม่เชื่อมระบบจ่ายเงินจริง
- เบอร์ร้านค้า/การตรวจสอบสิทธิ์: อยู่ในโค้ดฝั่ง client ไม่ใช่ authentication ระดับ production
- ขนาดกระดาษพิมพ์ใบเสร็จตั้งไว้ที่ 80mm บางเบราว์เซอร์ (เช่น Safari) อาจไม่รองรับค่านี้
  อัตโนมัติ แนะนำตั้ง Custom Paper Size เป็น 80×200mm เองตอนพิมพ์ถ้าเจอปัญหา
